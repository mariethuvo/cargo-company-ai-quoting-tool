## Problem Statement

Denver Cargo's sales team currently prices freight quotes manually: a dispatcher or account rep looks up comparable historical lanes, checks capacity by phone or email with dispatch, and estimates a rate by hand, a process that typically takes anywhere from 30 minutes to several hours depending on how busy the team is. This manual turnaround means Denver Cargo routinely loses time-sensitive shipments to competitors who can return an instant or same-day quote, and it produces inconsistent pricing across reps since no two people estimate a lane the same way. The cost is twofold: lost deals to faster-quoting competitors on common, low-risk lanes, and analyst time wasted re-deriving straightforward quotes that don't actually need a person's judgment — time that could instead go to the genuinely complex or high-risk shipments (unfamiliar lanes, hazardous cargo) that do warrant a human's attention.

## What this is

A single self-contained HTML prototype that proves the core AI interaction described in our Feature Spec: a customer submits shipment details, and an LLM (Claude, via Anthropic's API) extracts the request into structured data, generates a recommended freight rate range, and assigns a confidence tier that decides whether the quote should be auto-sent to the customer or routed to a human analyst for review.

This directly demonstrates Section 2 (Proposed AI Capability — structured extraction + generation) and Section 4 (User Interaction Flow) of our Feature Spec.

## Features

- **Shipment intake form** — origin, destination, weight, packaging, pallet requirements, pickup date (single date or range), pickup time window, delivery lead time, commodity type, and special requirements.
- **Live route map** (Leaflet + OpenStreetMap/Nominatim geocoding) showing origin and destination pins with a connecting line.
- **AI-generated logistics breakdown** — distance, recommended truck type/count, packaging advice, and a rate range with a plain-language explanation of the math behind it.
- **Confidence tiering** — every quote comes back tagged `high` / `medium` / `low`, visually color-coded, which is meant to drive whether a quote can go out automatically or needs analyst review.
- **City and weather visuals** — pulled from Wikipedia/Wikimedia (with an Unsplash fallback) for city skyline photos.
- **Light/dark theme toggle** and a simple team-member login screen for demo purposes.

## How to run it

1. Get an Anthropic API key at [console.anthropic.com](https://console.anthropic.com/).
2. Open the HTML file in a text editor and find the line near the top of the `<script>` block:
   ```js
   const API_KEY = "[API_KEY_HERE]";
   ```
   Replace `[API_KEY_HERE]` with your real key.
3. **Don't just double-click the file to open it.** Anthropic's API blocks the "null" origin browsers send for `file://` pages, so serve it locally instead:
   ```
   python3 -m http.server 8000
   ```
   Then open `http://localhost:8000/<filename>.html` in your browser.
4. Pick a team member on the login screen, fill in a shipment request, and click Generate.

## Why a special header is needed

Most LLM provider APIs are designed to be called from a server, not directly from a browser — a browser-embedded API key is visible to anyone who opens dev tools, so most providers block this by default. Anthropic's API allows it, but only with an explicit opt-in header (`anthropic-dangerous-direct-browser-access: true`), which you'll see set in the fetch call in this file. The name is intentional: this pattern is fine for a local prototype/demo like this one, but is **not** how this would be built for real customers — in production, the API call would move to a backend server so the key never reaches the browser at all.

## What's real vs. simulated in this prototype

- **Real:** the API call to Claude, the structured tool-use response, the confidence tier logic, the map/geocoding, and the city photo fetches.
- **Simulated / AI-generated, not live data:** the weather shown for each city is generated by the model itself as part of its structured response — there is no separate weather API call in this file. Treat it as illustrative, not a live forecast.
- **Not connected to anything real:** Denver Cargo's actual capacity, historical lane rates, or customer records don't exist for this class prototype — the rate recommendation is the model's own estimate based on general freight-market knowledge, not a real company database.

## Known limitations (see full Model Limitations section in the Feature Spec doc)

- Self-reported LLM confidence is not a calibrated statistical score — it's the model following instructions in the prompt, not a probability.
- The rate estimate has no backing from real historical Denver Cargo data.
- **Open item as of this commit:** a hard block for illegal/prohibited cargo (explosives, weapons, controlled substances, etc.) was built for an earlier version of this prototype but has not yet been ported to this file. Do not treat this version as safe for that edge case until it's added.
- **Open item:** this file has a live Anthropic workspace ID hardcoded (search for `WORKSPACE_ID`). Confirm with the team whether that should be replaced with a placeholder before making this repo's history permanent, since GitHub retains old commits even after a later edit.
